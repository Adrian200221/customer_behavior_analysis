# customer_behavior_analysis
proyecto de análisis de datos que muestra el análisis del comportamiento de clientes utilizando python, sql y power bi

Este proyecto de análisis de datos tiene como objetivo extraer información valiosa a partir de un conjunto de datos utilizando herramientas modernas de análisis y visualización.
El flujo de trabajo incluye carga y limpieza de datos en Python, análisis exploratorio (EDA), consultas SQL, creación de dashboards en Power BI y elaboración de reportes y presentaciones ejecutivas.

El proyecto fue desarrollado siguiendo buenas prácticas de análisis de datos para facilitar la toma de decisiones basada en información.
